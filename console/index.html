方法边界

能耗/碳排为 token-profile 估算：green-meter 用标定系数从 token 用量推算 GPU 运行能耗， 再乘以电网碳强度换算碳排，不是硬件实测（实测需 vLLM green-meter 插件）。
「已省 API 费用」= 同量 token 的云端 API 计价 − 本地电费估算；「已省碳排」= 相同能耗按云端电网 碳强度折算 − 本地碳排。请按实际服务价格与本地电源结构配置上面的基线。
